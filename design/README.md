## 设计理念 — “温暖的技术感”

这是一款桌面工具，整体质感应接近纸与墨，而不是网页仪表盘。

- 暖白外壳（`#F8F6F1`）与纸张色画布（`#FBF9F4`），编辑器使用干净的白色纸面。
- 墨色文字（`#17171A`），只保留一种焦橙色强调色（`#D4541F`），用于焦点、选中状态和活动节点。
- JSON 是主角：编辑器使用 SF Mono / JetBrains Mono 12.5 px，图形节点使用 10 px；保留熟悉的红色键名、蓝色字符串、绿色数字语法语言。
- 深色主题是真正的墨色主题（`#0E0E10` / `#17171A`），不是简单反相的浅色主题。
- 图形节点看起来像小型数据库表：头部显示名称、类型和数量；主体是键值行；连接处用端口圆点标记。
- 对比视图沿用纸面质感，做成并排差异，并配暖红/暖绿底色和基于路径的变更列表，而不是另一个独立工具窗口。
- 代码生成被呈现为一件精心制作的产物：语言选择器、语法高亮纸张、文件名、输出大小，以及复制/下载集中在同一处。
- 流数据是一等公民：JSONL 以可读的行尾部打开；`.jsonl.zstd`（DeepSeek harness 日志）采用增量解码，同时用实时事件面板汇总 `ts / level / event` 记录。
- 同一条流在右侧栏拥有三个标签：**实时流**、**会话**、**审计 N**。会话是 assistant-ui 风格只读线程，包含用户/助手消息、思考过程、工具调用、代码块、流式光标和会话侧栏，让对话日志真正适合阅读。
- 安全状态可见，而不是被埋在设置里：目录穿越、文件读取、上传、删除等工具活动可在审计设置中选择，并在审计标签中带计数呈现，同时给出阻止/允许的决策。
- JSON 可以变成本地 API：Mock 项目页负责创建和管理项目与接口，导入 JSON Schema 生成示例接口，按响应结构生成多条真实感数据，并导出 JSON Schema 或 OpenAPI/Swagger，全部在本机完成。一个共享 Mock 服务持有端口（HTTP 或 HTTPS），每个项目挂载到自己的路径下。

活动栏是一级外层框架；各工具栏及其工作区内容位于右侧的 `workspace-main` 列中，因此每个模式的工具栏在视觉上都归属于当前活动栏区域。

JSON 工具与实时流采用相同的两级结构：**一级**是最近文件列表（最近 JSON 文件、搜索、新建文件/打开文件、每行打开/删除）；**二级**是单文件编辑器。编辑器工具栏包含返回最近文件的操作，并在文本、分栏、图形、代码和表格视图中保持可见。对比、实时流和 Mock 会用自己的二级工具栏替换它。

响应式原型：当浏览器视口小于固定窗口时，整个窗口会等比缩放。

真实应用最小尺寸：1100 × 720；低于该尺寸时，搜索面板会变成覆盖式抽屉。

## 交互设计

- **分栏 / 图形 / 表格 / 代码 / 文本**分段控件；图形模式会缩放并居中场景。图形支持可用的缩放、适应、锁定、吸附、水平/垂直布局切换，节点可拖拽且连线随布局重绘；搜索面板的数据来自当前 JSON 文档。
- **JSON 工具导航（一级 / 二级）**：活动栏的 JSON 工具图标打开 **最近文件**，列出自最近打开过的 JSON 文件，包含路径、大小、行数、最近打开时间和 **打开 / 删除** 操作。一级工具栏提供文件搜索、**新建文件** 和 **打开文件**；状态栏汇总最近文件。选择文件（或新建/打开文件）进入二级 **单文件编辑器**；文档工具栏的返回操作回到最近文件。二级工具栏提供 **文件名下拉**，样式参考对比视图的 A/B 文件芯片：列出最近文件（当前项勾选），底部是 **新建文件**、**打开文件…** 和 **导入 CSV…**，因此无需离开编辑器即可切换最近文件、打开 JSON 文档或把 CSV 转成 JSON。JSON 工具与 JSONL 最近列表在文件列共用暖色文件图标（桃色图标底 + 强调色字形）；ZSTD 文件保留独立徽标颜色。打开另一个文件会替换当前文件，打开过或未命名的文件会加入最近列表。
- **单 JSON 文档**：二级编辑器一次只编辑一个文件（没有标签条）。当前文件名位于工具栏下拉中，标题栏始终显示 `Json tool`；下拉列出最近 JSON 文件（当前项勾选），后面依次是 **新建文件**、**打开文件…**（原生选择器）和 **导入 CSV…**（CSV → 对象数组）。选择最近文件、创建文档或打开文件都会替换当前文档。状态行更新行数和大小；**保存 / 格式化 / 压缩 / 校验、视图切换和搜索** 在图形、代码、表格视图中仍然可用。文档 **更多** 菜单可将当前文档导出为 CSV 或 Excel。其他分析视图仍使用电影演示数据，生产版会绑定当前文档。
- **对比工作区**：从活动栏或 ⌘⇧C 进入；两个对齐的编辑器（A 原始 / B 修改），支持结构化对比与文本对比、忽略键顺序、红色/绿色行内高亮、双栏同时描边选中变更，以及带新增/删除/修改筛选的变更面板。文件选择会重新读取真实 JSON 内容，并重新计算行对齐差异与结构化变更路径；A=B 时显示空差异，交换、对比、全部折叠、自动换行、同步滚动均可用。A/B 文件芯片会打开最近 JSON 文件下拉或原生文件选择器，并同步更新工具栏与面板标题；状态栏显示所选路径、实时行数和同步滚动状态。每个面板标题都有独立的 **搜索** 按钮：打开内联查找栏，支持命中高亮、结果计数、上一个/下一个（Enter / Shift+Enter）和 Escape 关闭，两侧可分别搜索且不会修改 JSON；切换文件后查找栏会重新索引。
- **代码视图中的代码生成**：可选择 JavaScript、TypeScript、Java、C#、Go、Rust、Swift、Kotlin、Python、PHP、Dart 或 JSON Schema；代码纸张会更新文件名、语言徽标、行数和语法高亮；可复制或下载生成文件。所有目标都会生成 **Root** 文档类型，页头显示根结构芯片（`Root · movies: Movie[] · meta: Meta`）。JavaScript 使用 ES6（模块、类、解构默认值、箭头函数，不使用 `??`）。目标包括：**JavaScript · TypeScript · Java · C# · Go · Rust · Swift · Kotlin · Python · PHP · Dart · JSON Schema**。原型会为所有目标模拟输出；生产版会从同一个中间类型模型渲染全部语言。
- **表格视图**：左侧保留源码，右侧变成嵌套表格纸张：区块标题（`movies` 数组、`meta` 对象）、对齐列、类型感知着色、类型标签、选中单元格的行/列高亮，以及 JSON 路径检查器底栏。行过滤、每张表的列显示菜单与重置，以及 **在源码中定位**（跳转到当前文档的对应行）均可用。CSV 导出位于文档的更多菜单（同时提供 Excel 导出）。在通用表格绑定完成前，表格仍展示电影演示数据。
- **搜索**：通过工具栏输入框或 ⌘F 打开；面板为当前文档建立实时 JSON 路径索引，可按全部 / 键 / 值筛选，显示路径和值片段并高亮命中，支持 ↑/↓ 与 Enter 跳转，并在源码中高亮目标行。⌘F 会路由到当前模块的搜索：对比面板查找、监控过滤、Mock 项目/接口过滤，或列表页的最近文件搜索。
- **文件菜单**（标题栏）：**打开 JSON 文件…**，以及打开 JSONL（⌘O）和 JSONL.ZSTD（⌥⌘O）。后两者会启动带过滤器的原生选择器，并直接进入二级监控详情的 **暂停** 状态；**最近** 区域同时渲染最近 JSON 文档和最近的 `.jsonl` / `.jsonl.zstd` 流（JSON 行进入单文件编辑器，JSONL 行进入监控；删除流会同步从菜单移除）。之后是设置…（⌘,），底部说明解释增量 zstd 解码。重复的保存/导出/导入/监控/审计入口已移除，这些操作现在位于文档下拉、文档更多菜单或命令面板中。
- **JSONL 流**：以静态方式打开时显示 30 行尾部，带语法高亮、行号、由 `ts / level / event` 派生的事件表、筛选器和文件结束状态。
- **监控导航（一级）**：活动栏的实时流图标打开 **最近流**，列出最近打开的 JSONL 和 `.jsonl.zstd` 文件，并显示格式、行数、压缩/解码后大小和最近打开时间。所有文件默认 **暂停**：打开文件不会启动监控，也不会有流在后台跟随。每行提供 **打开** 和 **删除**；点击行本身也进入二级监控详情。返回列表会结束会话，并将所有文件重置为暂停；关闭应用不会留下任何监控进程。一级 **打开文件** 按钮会调起针对 `.jsonl` / `.jsonl.zstd` 的原生选择器；所选文件会加入列表顶部，并以暂停状态在二级打开。监控工具栏 **更多** 菜单提供重新加载流、复制文件路径、导出事件和从列表移除。删除行会从最近列表移除（原型不会触碰磁盘文件）并更新计数。
- **两个独立轴**：监控工具栏保留 **源码 / 对话** 主切换，右侧栏则有独立的 **实时流 | 会话 | 审计 N** 标签。侧栏标签在两种主模式下都可用，且不会改变主视图；源码 ↔ 对话切换会保留所选侧栏标签，并将对应面板移动到该模式的侧栏。
- **右侧栏标签**：实时流显示 zstd 统计和实时事件列表；会话显示会话 id、当前/历史模型、轮次和工具调用；审计显示审计面板。只有在存在条目时，审计标签才显示总数。
- **JSONL / .jsonl.zstd 监控（二级）**：每个文件打开时都是 **暂停** 状态，工具栏提供 **跟随** 操作；跟随意味着像 `tail -f` 一样追踪文件。实时状态会显示实时徽标、脉冲尾部、自动跟随边、压缩大小与解码大小、压缩比、帧数、速率、缓冲区上限，以及带新事件高亮的事件列表。`.jsonl.zstd` 显示流式 zstd 统计；普通 `.jsonl` 隐藏压缩行。每个最近文件在详情视图中保留自己的名称、路径、行数和大小。harness 文件以 **对话 + 会话** 打开；普通 JSONL 文件以源码打开。每个文件都提供相同的跟随/暂停控件。源码视图只需一次切换，侧栏标签保持独立。`model.switch` 事件会显示在原始流和事件列表中。过滤输入框和级别芯片会筛选事件；事件行可选中；自动换行、跳转到实时、对话搜索和跳转到最新均可用；删除流也会同步从 文件 → 最近 中移除。
- **对话监控**：只读的 assistant-ui 线程，包含右对齐用户气泡、助手卡片、折叠的思考过程（“Thought for 0.8s”）、工具调用卡片（成功 / 错误）、语法高亮代码块、token 用量、流式光标、只读输入区，以及会话面板（会话 id、当前模型、历史模型、轮次、工具调用、汇总 token）。源码视图仍在主工具栏一次切换之外。
- **源码主视图**：原始 JSONL 尾部，带行号、实时边和 `model.switch` 记录。右侧栏可以同时显示实时流、会话或审计。
- **多模型会话**：对话头部显示模型数量；每条助手消息标注产生它的模型；`Model switched · R1 → V3` 分隔线标记切换；会话面板列出 **当前模型**（CURRENT 徽标）和 **历史模型**（切换时间与 token 用量）。会话总量汇总两个模型。原始事件列表包含对应的 `model.switch` 记录。
- **Assistant-ui 映射（实现）**：使用 `ThreadPrimitive`、`MessagePrimitive`、`ComposerPrimitive`（只读）、`ThreadPrimitive.Viewport` / `ScrollToBottom`、`ToolFallback` 和 `ActionBar`；将 JSONL 记录中的 `role=user|assistant`、内容分段、思考过程、工具调用和流式分块映射到这些原语。
- **审计标签**：以相同宽度替换右侧栏内容（源码模式 400 px / 对话模式 360 px），包含严重级别筛选（全部 / 严重 / 警告 / 信息）、工具/文件行、`已阻止` / `已允许`、目标路径或命令、工具/时间/会话元数据、阻止规则，以及操作（查看原始事件、确认、复制路径）。源码和对话主视图都可使用。选中行会原地展开；标签文字带有审计总数，没有条目时隐藏。
- **审计设置**：模态框，包含 **目录穿越、文件读取、文件上传、文件删除、Shell 执行、网络外发** 复选框。只有勾选的类别会出现在审计标签并计入数量。也可从审计标签的齿轮和审计侧栏的设置按钮进入。
- **全局设置**：活动栏齿轮或 文件 → 设置…（⌘,）打开统一设置对话框。**界面语言** 在 English 和简体中文之间切换；**主题** 提供浅色 / 深色 / 跟随系统；**Mock 服务** 提供共享 **端口**（1024–65535）和 **HTTPS** 开关。主题会实时预览；界面语言只在点击 **保存设置** 后生效（取消会丢弃待应用的语言）。语言与其余设置一起持久化。最后的 **关于** 区域重复产品信息（JSON Studio、版本、发布时间、MIT 许可证、运行时），并提供可用的 **检查更新** 操作，先显示“Checking…”，再显示“You are on the latest version”。同样内容也可通过标题栏 **帮助** 按钮以独立的关于对话框打开。语言切换双向覆盖整个界面：静态外壳、动态列表与对话框、菜单、工具提示和占位符都会立即更新，而示例代码、JSON 值、聊天消息和文件名保持不变。设置对话框、Mock 项目/详情、JSON 工具、JSONL 监控、对比工作区、表格/代码视图和审计界面共用同一套文案目录与 DOM 本地化器。
- **帮助 / 关于**：标题栏帮助图标打开关于对话框，显示软件名称（JSON Studio）、版本 1.0.0、发布日期 2026-10-26、MIT 开源许可证、Tauri 2 运行时，以及可用的 **检查更新** 流程（Checking… → 已是最新版本）。相同信息与更新检查也出现在设置末尾，因此从任一入口都能查看产品与更新信息。
- **共享 Mock 服务**：一个本地服务持有端口和协议（`http`/`https`）。项目永远不定义自己的端口；每个项目挂载在 `/<project-slug>` 下（例如 `http://localhost:4010/movies-api`）。项目卡片显示挂载路径，新建项目对话框可编辑挂载路径，复制 URL / TypeScript / cURL / Python / OpenAPI 都使用共享基础 URL。
- **Mock 导航（一级）**：活动栏的 **Mock 服务** 图标打开 **Mock 项目** 主页，不显示下拉。页面显示项目数量/运行中/接口统计、搜索、新建项目按钮，以及每个项目一张紧凑卡片。每张卡片使用底部栏：左侧是接口数量、挂载路径和最近更新时间；右侧是 **打开项目** 和 **启动/停止**。卡片刻意不显示基础 URL 行或复制操作；服务器地址位于项目详情中。
- **项目卡片**：点击任意位置或 **打开项目** 进入项目详情；**启动/停止** 挂载或停止项目路由；更多菜单提供 **编辑项目**、**导出 JSON Schema**、**导出 OpenAPI** 和 **删除项目**。虚线新建项目卡片和工具栏按钮都可创建项目。
- **Mock 项目详情（二级）**：动态渲染的接口列表，带方法徽标和可用的接口过滤；接口编辑器（方法菜单、路径、状态码、延迟、启用开关、响应 JSON）；**请求代码标签** — 响应、Headers、示例、Schema，然后是 **TypeScript / cURL / Python**；服务检查器（项目基础 URL 与挂载路径、共享端口、运行时间、请求数、启动/停止）；导出卡片和实时请求日志。方法切换、测试请求、格式化 JSON、四个 JSON 标签页以及项目感知的生成/导出均可用：生成会写入当前接口结构，Schema/OpenAPI 导出使用当前项目的接口，并遵循全部接口 / 包含示例 / 格式化输出选项。返回箭头回到项目页；项目切换只从项目页进行。
- **自动保存**：接口编辑器 **没有保存按钮**。路径编辑会防抖 450 ms 后保存到项目；启用开关会立即保存。未提交的编辑会在失焦、Enter 或切换接口时刷新，因此切换行不会丢失修改。编辑器底部显示 **Saving… / Auto-saved just now** 和状态圆点；页头没有保存指示。生成/导入的元数据会保留，路径变化时 TypeScript / cURL / Python 标签会重新渲染。
- **删除接口**：编辑器标题栏有带文字的 **删除** 操作。点击后打开确认对话框，显示方法、路径、名称和位置（`endpoint 2 of 4`）；确认后移除路由、选择下一个（或上一个）接口、刷新计数和请求日志，删除最后一个路由时显示空状态。删除接口不会删除项目。
- **请求代码**：**TypeScript** 会从响应示例推断返回接口，并从接口推断参数类型 — 路径参数变成 `XxxParams` 接口，POST/PUT 生成 `Omit<Response, "id">` 请求体，函数返回类型为 `Promise<ResponseType>`。cURL 显示带 `--request/--url/--header/--data` 的 shell 命令；Python 显示带类型的 `requests` 片段。代码片段使用当前项目基础 URL 和接口方法/路径，替换示例路径参数，跟随接口/项目选择，并支持复制。
- **复制请求 URL**：接口编辑器标题栏有单击 **复制 URL** 操作；行列表和项目卡片刻意不提供重复复制按钮。复制值是完整可调用 URL — 协议 + 共享端口 + 项目挂载 + 路径，其中的 `:params` 会替换为示例值（例如 HTTPS 开启时的 `https://localhost:4010/movies-api/movies/tt0944947`）。检查器中的基础 URL 仍可复制。每次复制都会通过 Toast 显示复制内容；非安全上下文使用 textarea 兜底。
- **生成 Mock 数据**：在 Movies 详情中，**生成** 会在检测到的数组中创建多条记录（记录数、种子、目标、选项、预览）；编辑器显示 GENERATED 徽标和记录/种子元数据。
- **导入 JSON Schema**：从接口侧栏或新建项目对话框进入。拖放/浏览 `.schema.json` 文件（或加载示例），选择定义、目标项目（或从文件创建项目）、基础路径和追加/替换模式。示例响应由 Schema 生成 — 支持本地 `$ref`、`examples`/`default`/`const`/`enum`、`allOf`/`oneOf`/`anyOf`、可空联合、数组、格式和数值边界。每个选中的模型变成 `/<plural>`；带 `id` 的模型还会生成 `/<plural>/:id`。追加模式会更新相同方法和路径的路由，而不是重复创建；导入的接口显示 `from <file>` 提示。
- **新建 / 编辑项目**：名称、描述、**挂载路径**（带共享服务前缀）、起始选项 — **空白** 或 **导入 JSON Schema**。对话框说明端口在设置中配置；没有每项目端口字段。选择 Schema 会把项目字段交给导入对话框，导入文件后才创建项目；编辑会复用同一对话框，预填值并提供保存更改。
- **删除项目**：破坏性确认，显示项目名称、接口数量和挂载 URL；从详情删除后会回到项目页。
- **新建接口**：方法选择器、路径、状态码、延迟、接口名称，以及响应来源（空白 / 复制现有）。
- **导出 Mock API**：JSON Schema 或 **OpenAPI 3.1 / Swagger** 格式卡片、全部接口/示例/格式化输出选项、文件预览和下载。JSON Schema 导出响应模型；OpenAPI 导出路径、Schema 和示例。
- **命令面板**：通过 ⌘K 或标题栏打开；支持实时过滤、↑/↓ 导航和 Enter 执行；格式化、压缩、校验、排序对象键、字符串转义/反转义、生成代码、与文件对比（原生选择器）、导出 CSV、导入、主题和设置均已接通。导入会打开可用的导入对话框。
- **导入**：通过 ⌘I 或文件夹按钮打开；提供 JSON / CSV / JSONL 标签、原生浏览或拖放区、格式感知解析（CSV → JSON 数组，JSONL → JSON 数组）、可选的替换当前文档行为、加入最近文件、50 MB 限制，以及成功/错误 Toast。
- **节点选择** 显示强调色描边；端口标记已连接的行。
- **状态栏** 显示 JSON 有效性和光标下的 JSON 路径。
- 键盘提示可见但不抢眼；对话框仅用于设置、导入和破坏性确认。

## Tauri 2 实现说明

1. **外壳**：自定义 38 px 标题栏和窗口内文件菜单。macOS 保留原生交通灯并使用覆盖式标题栏；为保持键盘和 App 菜单一致性，将文件菜单和 Mock 项目操作同步到原生 Tauri 菜单。Windows/Linux 在右侧渲染自定义窗口控件。
2. **编辑器**：使用 CodeMirror 6（比 Monaco 更轻），配置 JSON 语言、折叠、括号匹配、搜索和与上述令牌一致的自定义主题。
3. **图形**：使用 React Flow 或自定义 SVG 画布。节点按需展开，并限制可见节点数量；超过约 1–2k 个节点时进行虚拟化或渲染简化节点。
4. **解析**：以源文本为唯一事实来源；通过 worker 或 Rust（`serde_json`）Tauri 命令对解析做防抖，以支持大文件。图形由解析树加源码偏移量派生。
5. **文件**：Tauri 对话框 + fs 插件；拖放；最近文件；自动保存/脏状态；UTF-8 检测；JSON/CSV/JSONL 导入与 CSV 导出。
6. **侧栏标签**：使用两个独立状态机 — 主视图（`source | chat`）和侧栏面板（`live | session | audit`）。侧栏标签永远不改变主视图；切换主模式时，将所选侧栏面板移动到该模式的侧栏。两种状态和审计计数都保存在共享状态中。
7. **表格**：从对象/数组节点派生区块；对大数组虚拟化行；将单元格点击映射到稳定的 JSON 路径和源码范围；CSV 导出应复用同一列模型。
8. **对比**：从解析树构建结构化差异（按路径键控；开启忽略键顺序时忽略顺序），文本模式构建 LCS 文本差异。两个编辑器保持行对齐并同步滚动；变更列表由同一差异模型派生。
9. **代码生成**：先将 JSON 归一化为中间类型图（对象、数组、联合、可空性、可选性），再按语言模板渲染。**始终生成 Root 文档类型**（例如 Go `type Root struct`、C# `public sealed class Root`），并保留嵌套模型；在页头芯片中显示其形状。JavaScript 仅使用 ES6 — 模块、类、解构默认值和箭头函数，不使用 `??`/可选链。目标除 JavaScript、TypeScript、Java、Go、Rust、Swift、Kotlin、Python、PHP、Dart 和 JSON Schema 外，还包括 C#（System.Text.Json 特性）。根名称、可选字段和只读选项在各生成器之间共享。
10. **JSONL 流**：逐行解析，虚拟化尾部，并维护有界环形缓冲区（默认 100k 行）。文件监视器驱动追加事件；通过重置流处理截断/轮转，并将“跟随”与“暂停”保持独立。
11. **zstd**：在 Rust 侧使用流式解码器。支持拼接帧和不完整尾帧；跟踪压缩/解压字节数、帧索引和最后追加时间。harness 追加新帧时重新打开/恢复。
12. **DeepSeek harness**：通过扩展名识别 `.jsonl.zstd`（`.zst` 作为别名），将 `ts / level / event` 和常见字段映射到事件卡片，并保持原始 JSONL 一键可达。
13. **对话线程**：使用 `@assistant-ui/react` 原语，并以匹配本设计的自定义主题。按会话/轮次分组记录；支持文本分段、思考过程、工具调用/结果和流式部分消息。监控模式下输入区保持只读（未来“回复”模式可复用它）。
14. **消息映射**：DeepSeek harness 日志存在差异；渲染前先将消息记录（`role`、`content` 分段、`tool_calls`、`reasoning`、时间戳、token 用量）归一化到内部消息模型。记录不像对话时回退到事件视图。
15. **多模型跟踪**：在每条消息上保存模型，维护包含切换时间的会话模型时间线，并从最新切换推导当前模型。分别按模型和整体汇总 token；绝不假设一个文件只有一个模型。对话头部显示模型数量，会话标签显示当前模型和历史模型。
16. **审计引擎**：从工具调用记录派生审计条目，按操作类型和严重级别分类，并标记允许/阻止。将规则和决策保存在条目中，让审计标签无需二次查询即可使用。启用的类别持久化到本地。
17. **审计投递**：将条目追加到有界本地审计环形缓冲区，通过审计标签及计数呈现。实时流和会话共享同一审计存储；设置全局生效。不上传网络。
18. **Mock 引擎 + 项目库**：维护本地项目库（项目 → 接口 → 示例）；一级 Mock 页面是项目浏览器，二级是运行中的项目。在 Rust（axum/hyper）中运行 **一个** 绑定到 localhost 的 Mock 服务，由全局端口和 HTTPS 开关配置；将每个项目挂载到 `/<slug>`，并在该前缀下匹配路径。项目启动/停止即挂载或卸载其路由。路由匹配支持路径参数、状态码/延迟、CORS 和请求日志；修改接口会热重载路由。默认绝不暴露非本地网络接口。
19. **Mock 导出**：从响应示例生成 JSON Schema，从项目接口生成 OpenAPI 3.1（兼容 Swagger）；支持 JSON 和 YAML、共享 Schema、示例和路径参数。OpenAPI 的 `servers.url` 是项目基础 URL（`scheme://localhost:<port>/<slug>`）。导出生成器应与运行中的服务解耦。
20. **JSON Schema 导入**：读取最大 10 MB 的 `.schema.json`；收集 `$defs`/`definitions`（或根对象 Schema），显示每个定义的字段数，并让用户选择类型、目标项目或新项目、基础路径和追加/替换模式。通过解析本地 `$ref` 并遵循 `examples`/`default`/`const`/`enum`、`allOf`/`oneOf`/`anyOf`、可空联合、数组、字符串格式和数值边界来生成示例。派生 `/<plural>` 集合路由；当模型有 `id` 时额外生成 `/<plural>/:id`。追加模式更新相同方法和路径的接口，而不是重复路由；导入的接口保留源文件信息。
21. **Mock 数据生成**：从响应示例推断数组、嵌套数组、可空字段和基础类型；使用确定性种子生成 N 条记录，包含唯一 ID、真实感值池，并保留可空性。限制记录数/响应大小，将生成的示例保存到接口上，并允许导出使用它。
22. **请求代码生成器**：根据当前项目基础 URL、接口方法/路径、Headers 和请求体，渲染 TypeScript fetch、cURL 和 Python requests 片段。TypeScript 从示例推断响应接口（包含嵌套数组/对象和可空性），生成路径参数和请求体类型，并标注函数返回类型。替换示例路径参数，为 POST/PUT 包含 JSON 请求体，并让片段与接口/项目选择保持同步。
23. **状态**：使用 Zustand 或类似方案管理 JSON 工具页（最近列表 / 编辑器）、最近 JSON 文件、当前文档、视图、选择、搜索、对比、流、监控页（最近列表 / 详情）、当前监控文件、监控模式、审计、Mock 项目/接口、生成数据和服务器状态；监控跟随仅限当前会话，离开详情时重置。主题和面板尺寸持久化到本地。
24. **安全**：使用最小范围的 Tauri capabilities，webview 不加载远程内容，设置大小限制并呈现清晰的大文件状态；Mock 服务仅绑定 localhost，并在本地记录请求。
25. **复制与反馈**：生产版使用 Tauri clipboard 插件（并提供浏览器兜底），为接口 URL、基础 URL 和代码复制提供统一的 Toast 辅助函数。请求 URL 会替换示例路径参数，使复制值可直接调用；路由模板仍在编辑器中可见。任何完成后没有明显视觉结果的操作 — 保存、格式化、压缩、校验、导出、复制 — 都必须以成功 Toast 结束，并指明受影响的文件或值；失败时使用错误 Toast。
26. **自动保存**：路径编辑防抖（约 450 ms），并在失焦、Enter、切换接口和项目导航时刷新待保存内容；持久化到项目存储并热重载运行中的路由。保存状态只放在编辑器底部（Saving… / Auto-saved just now），绝不放在接口页头；保存时不要覆盖生成/导入的元数据。同一管线可在生产版中支撑 CodeMirror 响应编辑器。
27. **接口删除**：从项目存储移除路由，重新计算当前索引，刷新计数/请求日志并热重载运行中的服务；删除前用方法、路径和位置确认。接口删除与项目删除相互独立；空项目仍应有效，并保留添加/导入入口。
28. **设置 + 外观**：持久化语言、主题（`light | dark | system`）、共享 Mock 端口和 HTTPS 标记。主题通过 `prefers-color-scheme` 解析 `system`，并在变化时更新；语言使用一套 i18n 文案目录加 DOM 文本/属性本地化器；静态标签、动态渲染、菜单、工具提示和占位符双向实时切换，而示例代码、JSON 值和文件名保持不变。Tauri 构建中通过 store/fs 插件持久化，而不是 `localStorage`；原型使用受保护的本地兜底。
29. **HTTPS Mock 服务**：启用时使用本地证书绑定同一端口，暴露 `https://localhost:<port>/<slug>`，并在复制/代码/导出中使用该协议。需要规划证书生成/续期和清晰的浏览器警告说明；每次服务运行中 HTTP 与 HTTPS 互斥。

- DeepSeek harness 的精确消息 Schema（独立消息记录还是工具事件），以及多少归一化应在 Rust 侧完成、多少在 UI 侧完成。

- 打包 Inter + JetBrains Mono，还是依赖系统字体？
- 以 macOS 为优先的外壳，同时为 Windows/Linux 提供自适应控件？
